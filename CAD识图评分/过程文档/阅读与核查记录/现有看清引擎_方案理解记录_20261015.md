## 对已有成果的定位

现有方案是在已有样本和实验条件下验证过的高精度感知/读取体系。它不是等待选型的OCR清单，也不是毫无实现的目标图。后续研发应复用该底座，不能因历史表格数字或口径有差异，就把整体读取方案重新降为未经验证。

“看清”不等于仅识别普通文字：它覆盖工程标注与符号、排版结构、位置、候选、原图证据、多信源分歧和人工确认。现有语义轴、视觉取证与会诊服务于“读出来的是否与图面相符”。

## 已有方案逐层理解

| 模块 | 职责与设计原因 |
|---|---|
| L0/L0g | 可用矢量/实体先读；CAD模板与几何提供读取及评测锚点；不同格式按其保留的信息分流 |
| L1 | 捕获分散标注，提供文字框、置信度和取证坐标，不单独承担全部特殊符号理解 |
| L2 | 文档视觉识读与符号/结构表达，补L1低频符号等短板；分区和尺度策略补散布漏采 |
| L3 | 归一并对齐同位置观察，区分一致、矛盾、单源、符号丢失；一致也有形态守卫 |
| L3.7 | 对争议区域做不携带既有OCR原文的中性转录，减少照抄和自证 |
| L4 | 多轴证据仲裁，不将单一模型自信分数当最终依据；早期Laya主裁假设已被实验修正 |
| L4+ | CAD与图面配准后定位盲区补读，用形态与数值限制防止错锚和双计 |
| L4b | 候选须有独立通道复现才具备特定放行证据；是独立机制，不与主裁重复投票混同 |
| L4c | 文本通道看整图终稿一致性，视觉通道回看整图；会诊点名用于降级/建议，不直接改写图面读值 |
| L5 | 留证据给人工判断，再形成带作用范围的先例与混淆记录；相似数值不能直接借先例放行 |
| E1/E2 | 识读判分与图面差异审计是不同维度，有自己的真值、位置和分母 |
| E3/E4 | 轮次版本化、缓存、回归和漂移观测，保证实验可追溯，避免覆盖基准与混入合成成绩 |

协作矩阵是“调用位点×引擎角色”：同一视觉引擎多处复用，但输入可能是小裁片、大语境裁片、整图或盲读，不等于六个独立模型投票。多模型数量本身不构成效果证明。

## 已读到的实验修正与决策

- 双引擎互补来自样张验证：捕获散布标注与识别符号语义的长短板不同。
- 早期φ→中担忧与后续退化实测有更新，实际守备重点改为Ø→0及符号丢失，不能只读开篇假设。
- Laya的原概率主裁设想被本任务负对照推翻，方向佐证与数值校准分开。
- L4c的auto触发有恒真信号排除和重复观测，既有默认auto不在本轮改变；特定验收配置与默认配置分别记录。
- 双后端投票已有负面实验：机制未产生实质降级，不能因两臂随机数字不同声称降低漂移。
- 35条捕获、纯自动比例、人工队列数量、整图报警分别属于不同评价口径。
- P07显示精度问题说明答案钥匙也需核查；不能把显示44.73与测量44.732的差异误认成模型读错。

这些修正说明方案经历了实验迭代，不是要求重新否定其整体价值。精确指标、配置状态和新图适用性继续保留原范围。

## 与项目目标的分界

| 层面 | 实际需要回答的问题 |
|---|---|
| 已有看清体系 | 某位置到底写的是28、26，还是带公差的复合标注？有没有漏符号？依据哪份图面证据采纳？ |
| 目标态看懂 | 此标注属于哪个孔/轴/表面？处于什么视图和零件/装配语境？与其他标注如何关联？ |
| 目标态为什么 | 在上述对象和语境下，哪条规则适用、例外是否成立、实际内容为何不符？ |
| 目标态怎么做好 | 改哪个对象、用什么正确表达、前提是什么、如何复检？缺设计条件时由谁确定？ |

例如已有读取体系可把`⌀42h7`准确读出来；目标态还须确认它标的是孔，才能应用相应规则，再解释和建议。不能为了让表达更合理先改读为H7，否则会掩盖原图差异。

三件套进入的是工程理解与判据应用层：知识补概念和原因，判据规定条件和依据，案例补具体对象语境、正反例及专家经验。不是简单把三个库全文塞给现有L4，就等于完成“看懂”。
