# CAD方案文档地图维护

主入口：[CAD方案文档地图](../CAD方案文档地图.html)。在本机浏览器打开即可展开、搜索、预览，无CDN和在线模型依赖。原文件只维护一份，页面是2026-10-20生成的来源快照，不自动监听磁盘变化。

## 使用

点击左侧主题展开主树；点击文档在右侧读正文、章节或关联。标题搜索默认开启，勾选“同时搜索导航内正文”可查已嵌入的正文。局部关系图区分原文引用和实验方案→结果的阅读编排，主树连线不代表产品实现或工程依赖。

原始PDF/DWG/DXF及大型过程目录只登记入口，不冒充已解析正文。历史记录与设计/实验结果分组，所有状态按原文范围解读。来源正文预览最多100000字符，超长正文标截断；完整文件通过“打开原文件”查看。搜索覆盖标题/章节和所嵌入正文，不保证检索未索引附件内容。

## 更新

在CAD识图评分根目录执行：

```sh
python3 方案导航资料/生成导航.py
python3 方案导航资料/生成导航.py --check
```

正常生成更新页面、台账和来源hash；--check只读检测来源内容与增删，不改文件。保留稳定节点ID.json；改标题不改ID，来源移动需登记ID迁移。新Markdown按规则分组，分类不合适时修改生成器规则再刷新；资料不移动也不删除。

若浏览器限制本地文件跳转，可运行只监听本机的预览服务：

```sh
python3 方案导航资料/预览服务.py --port 8842
```

浏览器打开 http://127.0.0.1:8842/ 。服务只读取地图和已登记ID，不支持任意路径。源文件hash变化返回409，需刷新地图，不无声展示另一版。目录入口只列已登记子项，完整实验工件仍在原目录。关闭服务不影响离线HTML和任何下载进程。
