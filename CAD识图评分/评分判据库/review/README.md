# CAD规范检查复核包

当前用于用户肉眼审核，已完成资料OCR与矢量交叉读取，尚未开展新图规范检查能力测试。先读../08_新增资料交叉复核报告.md和../06_全量复核报告.md和../02_T01-T05_纠错点_国标映射.md，再逐项看pack_v1。

- T卡20张：覆盖19条客户标签的条款候选，另1张是角度补充条款。
- C卡4张：覆盖8条标签的经验候选，待客户专家核准。
- W卡5张：标准依据已补，保留卡号继续审查案例适用性，不自动判定。
- N卡4张：限定范围检索审计，不证明所有国标无明文。
- R卡2张：引文位置核查项，不计入32条客户标签。

共35张卡。卡内audit是本轮已读原资料后的审查意见，不是盲审或客户批准。机器引文状态已撤销旧结果并标为待重核。当前无真实API能力通过记录。

## 路径及阅读

所有file字段相对评分判据库根目录。T卡context原页包含完整上下文，客户正误PDF便于查看。不要只看裁图与短引文。所引用的原始PDF位于父目录国标和工程图审核；分发时一起提供这些资料及evidence，单独复制pack_v1不完整。

优先看T01-3花键、T01-6符号、T01-7例外、T01-8尺寸、T04-6省略例外、T05-4标签争议、T05-5线宽。疑点记录到responses，填写证据页码/图上位置、理由和建议，不能只填通过。

## 反馈与下一步

客户原标签不覆盖改写。用户肉眼审核后确认目标、待资料项和经验规则，再冻结一小组规则做样例回测。仅以识别能力和规则输入能够验证样例能力；新图泛化需后续增加不同图纸。

review/manager为管理侧答案，不进入外部盲审包；已有audit意见若随包分发，应称协同复核。
