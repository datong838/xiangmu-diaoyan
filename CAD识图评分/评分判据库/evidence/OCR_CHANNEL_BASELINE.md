## 二、判定分布

| 等级 | 份数 | 对否定结论的含义 |
|---|---|---|
| A-权威 | 5 | 双通道可交叉验证，否定结论可信 |
| A-部分 | 2 | 通道A残缺，否定结论须通道B承担 |
| A-弱 | 0 | 同 A-部分 |
| A-乱码 | 5 | ★ 假文本层，不构成交叉验证 → 等同 B-唯一 |
| B-唯一 | 6 | 单通道，否定结论需人工抽查 |

| 依赖标准 | 对应 convention 规则 | 通道等级 | 否定结论是否可双通道验证 |

| 4458.1 | L2-PROJECTION-001 | **A-权威** | ✅ 是（A 文本层 + B OCR 双通道） |

| 4457.4 | （辅助：图线，供 L1 参考） | **A-部分** | ⚠️ 部分（A 残缺，以 B 为主，须 C 抽查） |

## 四、纪律

1. **A-权威**的标准：否定结论可由文本层独立验证，可信。
2. **A-部分 / A-弱 / B-唯一**的标准：否定结论为**单通道或弱通道**，
   必须在判据条目的 `ocr_dependency` 字段显式标注，并列入人工抽查清单。
3. 任何**新增** convention 判据，入库前必须过本基线——
   若其反查标准是 B-唯一，则该条 convention 定性的置信度自动降一级。
