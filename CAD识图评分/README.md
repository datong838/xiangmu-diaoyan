## 文件治理规则

1. 同一份现行文档只维护一个实体；分享副本或压缩包不回流为新主版本。
2. 新方案放全套建设目录；阅读笔记、评审、自查与费用放过程目录；原始资料和实验工件不能混入现行方案。
3. 同名但不同内容先审差异；旧稿归档并标明替代来源，不拼接互相冲突的决定。
4. 资料、设计、实验实测、专家核准及产品验收分别记录，不因目录合并改变其状态。
5. 旧路径与历史哈希通过[迁移清单](过程文档/文档治理/迁移清单_20261016.json)追溯；历史JSON快照保留原样，不能用其原路径判断资料丢失。
6. 主方案中的两个目标态文档分别承担范围/契约和总体能力设计，均为草案；相互冲突须评审解决，不能仅按文件时间覆盖。
