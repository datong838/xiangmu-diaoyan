# 第一部分　目标态定义

## 1.1 一句话目标

> **让机器对一张机械 CAD 图纸，达到"看清 → 看懂 → 知因 → 判合规"的完整能力，
> 且已检查范围内的结论都能追溯到图面证据及经核准的适用依据，可复核、可审计；未检查和无法判定项明确列出。**

## 1.2 四层能力分解（本方案的骨架）

| 层 | 能力 | 用户原话 | 判据 | 现状 |
|---|---|---|---|---|
| **C1 看清** | 按检查范围读取文字、符号、图线及位置并保留证据 | "看清" | 分类覆盖率、读取正确率、漏读与误读 | 指定35个尺寸/工程标注条目人工闭环捕获35/35；全图覆盖未建立基线 |
| **C2 看懂** | 知道画的是什么对象 | "看懂" | 对象识别准确率 | 🔴 **主要瓶颈** |
| **C3 知因** | 知道为什么、怎么改 | "知道为什么和怎么做" | 可给出条款+解释+修正建议 | 🟡 部分（判据有，解释弱） |
| **C4 判合规** | 每一处符号是否合规 | "知道每一处符号是否合规" | 逐符号判定 + 条款溯源 | 🟡 符号类受阻 |

### 1.2.1 现状判定：对象理解是关键缺口，C1与C2仍需并行完善

32 条复核的实证数据：

| 层级 | 通过 | 应用层确认 | 说明 |
|---|---:|---:|---|
| 命题层（结论含通过） | **21 项** | — | 含部分或子命题通过，不能等同21条完整可执行规则 |
| 应用层（能套到图上） | — | **1 条** | **只确认了 T05-5** |

**不能把命题层与应用层的数量差直接归因为C2。** 逐项区分读取、对象归属、关联、适用条件和图外设计条件的阻塞。35/35仅为既有有限条目的人工闭环捕获结果，不是全图或无人值守准确率。

典型证据：

| 条目 | 国标说了什么 | 卡在哪 |
|---|---|---|
| T03-1 | 装配图相邻件剖面线方向相反 | 先得知道是**装配图还是零件图**——判反即系统性误报 |
| T05-3 | 滚动轴承不画剖面符号 | 先得认出「这是滚动轴承」 |
| T04-2 | 移出断面轮廓用粗实线 | 先得认出「这是移出断面」 |
| T01-8 | 孔大写 H / 轴小写 h | 先得知道这个 Ø 是孔还是外圆 |

> 国标提供规范依据；对象理解由教材语义、几何关系、视觉证据、案例和专家共同支撑，不能只依赖案例数量。

## 1.3 设计内核（三条，贯穿全案）

### 内核一：**先格式后数字，格式可疑一律 fail-closed**

> `Ø50` 不是 `050`，`φ20` 不是「中 20」。
> 宁可交人工，不静默放行。

### 内核二：**精度靠结构化数据，不靠模型"看"**

第三方实证（BlueprintSymVL）：VLM 在工程蓝图符号识别上
- 密集环境性能退化
- 视觉相似符号混淆
- **"a concerning propensity to hallucinate symbols"**（会幻觉符号）
- 结论：**not yet suitable for autonomous deployment**，最佳定位是 human-in-the-loop

行业实测五种路线：**纯图像全败，DXF 结构化提取 + 截图校正胜出**。

### 内核三：依据分型核准，未核准或不适用即不得确定判定

- 国标规则：记录标准版本、条款、原页、审核及适用条件；`clause_verified=false`不得输出国标违规结论。
- 专家/手册经验：记录来源、审核人、版本及工艺条件；不强制虚填国标条号，输出类型为经验建议或约定要求。
- 教材知识：支撑对象、符号及原因解释，不自动升级为强制判据。
- 参考答案约束：记录独立核准的答案包、允许变体与版本；先判断差异，再判断是否违规。

来源核准不等于适用性成立；事实或前提不足返回PENDING/无法判定。

# 第三部分　C1 看清：数据获取层

## 3.1 数据源优先级与输入责任

**PDF是客户主输入，DWG/DXF是可选增强。** 下表表示结构化信息丰富程度，不表示产品交付必须取得CAD源文件。PDF-only独立验收；按每页/每区域路由原生文字、转曲图线、扫描图和隐藏OCR文字层，任何一层不能自动跳过图例与符号复核。CAD存在时先核对文件版本、图号、变体与PDF对应关系，再用其增强证据。

| 优先级 | 源 | 可用信息 | 限制 |
|---|---|---|---|
| **P0** | **DWG/DXF** | 文字、线型、尺寸、图层、块 | 需转换（有损） |
| P1 | PDF 矢量 | 几何、线宽、坐标 | 文字转曲、dash 展平 |
| P2 | PDF 扫描 | 仅图像 | 全依赖 OCR |
| P3 | 图片 | 仅图像 | 最差 |

> **已实证**：10 张图纸 PDF 全部"有矢量层但文字转曲"——`Ra 6.3`、`H7`、`1:10` 读不到。
> 这里缺失的是可直接提取的字符编码，不等于图面信息不存在；文字转曲后仍可通过图像识读及几何证据恢复，须验证正确性。

## 3.3 L0g 三轴源事实提取（参考答案须另行核准）

### 轴1｜DIMENSION实体 → 尺寸事实

分别保存原始模板、测量缓存、几何接口测量、覆盖文字、样式/精度、显示块和PDF原图证据。源DWG包含正误变体，原生字段不得直接作为专业正确答案；仅在图号/变体/对象绑定及显示核准后进入参考答案包。

**实测模板形态**：

```
{%%c<>}                                          直径+测量值
{%%c<> H7}                                       直径+公差带（孔，大写H）
{%%c<> h7}                                       直径+公差带（轴，小写h）
{%%c<> f7}                                       直径+公差带 f7
{\A1;{%%c<>}{}{\H0.71x;\C2;\S+0.028^ +0.003;}}   直径+堆叠公差
{\A1;{<>}{}{\C3;%%p0.1}}                         对称公差 ±
{4*M<> EQS}                                      4×M□ 均布
{M<>-6H}                                         螺纹 M□-6H
{90%%d}                                          角度 90°
```

**堆叠公差格式确认**：`\S上偏差^下偏差;`
**控制码**：`%%c`=直径、`%%d`=度、`%%p`=±

### 轴2｜图层/线型 → 线型事实（★本方案新增）

**这是原五层体系没有的轴，建议新增。**

线型表定义完整可读：

| 线型 | 定义 |
|---|---|
| `CENTER2` | `Center (.5x) ___ _ ___ _ ___ _` |
| `PHANTOM4` | `Phantom (.25x) ___ _ _ ___ _ _` |
| `DASHED2` | `Dashed (.5x) _ _ _ _ _ _ _ _ _` |
| `DASHED` | `__ __ __ __ __ __ __ __ __ __` |

**价值**：
- 可程序化提取源格式事实，不依赖模型猜测；但提取字段不等于规范判定。
- 核对实体显式线型、BYLAYER/BYBLOCK继承、块变换、线宽与线型比例，不能只按层名推断实际显示。
- T02-5/T04-3须进一步完成对象用途、几何关系、适用条件和显示证据绑定，验证后才能判定。

**待追异常**：`9双点划线层` 仅 **1** 个实体。若某孔中心线本应用点画线却落此层，可直接定位——这正是 T02-5 的判定入口。

### 轴3｜几何拓扑 → 对象候选（C2 的输入）

从 LINE/ARC/CIRCLE/HATCH 的拓扑关系生成对象候选，供 C2 判定。

## 3.4 🔴 已知不可达区（必须显式标注）

| 盲区 | 原因 | 出路 |
|---|---|---|
| **8符号标注层94个代理**（其余22个为普通实体） | 代理的原生业务参数未核准；显示缓存与语义分开 | 核验对应Object Enabler / 源CAD副本导出，视觉与人工补证 |

## 3.5 ⚠️ DWG→DXF 有损（已实证）

| 项 | 核查结果 |
|---|---|
| 未导出到 DXF 的句柄 | **382**（31 组匿名块及其内部实体） |

# 第四部分　C2 看懂：对象识别层（★重点建设）

## 4.1 为什么这是主要瓶颈

C1在有限条目上已有人工闭环证据，21项含命题或子命题支持；全图读取、对象归属和条件适用仍有缺口。C2是重点建设项，但不能代替C1补盲和逐条规则核准。

## 4.2 建设路径：四类识别器

| 识别器 | 判什么 | 方法 | 可信度 |
|---|---|---|---|
| **R1 图纸性质识别器** | 零件图 / 装配图 | 标题栏 + 件号 + BOM + 视图数 | 高 |
| **R2 标准件识别器** | 轴承/螺纹/齿轮/弹簧/键 | 特征几何 + 国标表示法 | 中高 |
| **R3 特征识别器** | 孔/轴/键槽/中心孔/倒角 | 几何 + 标注语义 | 中 |
| **R4 视图类型识别器** | 主视/剖视/断面/局部/向视 | 视图关系 + 标注 | 中 |

### 4.2.1 R1 图纸性质识别器（优先级最高）

**原因**：T03-1 是 **P1 级系统性误报风险**——装配图 vs 零件图语境下结论相反。

**判据来源**：GB/T 4457.5 §4.7 等三条（相邻件剖面线方向相反 / 间距不同 / 同一零件各视图方向一致间距相同）

**⚠️ 当前阻塞**：T03 在 DWG 中**只有一个变体**（组5，Main_3，26 个标注），**无配对正确图**，且 `10D0 = {%%c<> h7}` 符合错误图线索。
→ **需补 T03 正确变体，否则 T03-1 应用层无法闭环。**

### 4.2.2 R2 标准件识别器（直接收益最大）

| 对象 | 国标 | 解锁条目 |
|---|---|---|
| 滚动轴承 | GB/T 4459.7-2017 | **T05-3**（不画剖面符号—**防误报**关键） |
| 花键 | GB/T 4459.3-2000 | T01 花键套 |
| 螺纹 | GB/T 4459.1-1995 | 螺纹画法 |
| 齿轮 | GB/T 4459.2-2003 | — |
| 弹簧 | GB/T 4459.4-2003 | — |

**T05-3 特别重要**：若把滚动轴承误判为普通零件，会因"没画剖面线"报错——**这是典型误报**。

## 4.2.3 对象与关联契约

构建图纸→图幅→视图→零件→特征，以及尺寸/符号/图线到特征的关联。每个对象或关系记录源文件哈希、页/图幅、坐标或句柄、来源通道、候选状态、审核与版本。

规则声明所需对象、关系、前提及例外；仅识别“这是孔”不足以断言某个H7标注属于该孔。关联缺失或冲突则返回无法判定。案例检索支持理解和解释，不能替代关系核准。

## 4.3 方法论借鉴：图层-块自动标注

**ArchCAD-400K**（同济+上海 AI Lab，NeurIPS 2025）：
- 用 CAD **图层名 + 块定义**自动生成标注，**标注效率提升 50 倍**
- 全矢量化标注，避免栅格化伪影

**适用于我们**：图层已高度语义化（`3中心线层`、`5剖面线层`、`8符号标注层`），可直接作为弱标注源。

## 4.4 反直觉提醒：堆图片解决不了 C2

| 喂法 | 效果 | 证据 |
|---|---|---|
| 喂更多图纸图片 | ⚠️ 有限 | BlueprintSymVL：密集退化、相似混淆、会幻觉 |
| 喂 DXF 结构化 + 案例 | ✅ 有效 | 行业实测 DXF 路线胜出 |

VLM输出不能直接替代精密几何度量。是否增加图像、案例或结构化输入，应按本项目对象识别与关联任务实测，不作“增加图片必然无效”的绝对判断。

# 第五部分　C3 知因 + C4 判合规

## 5.1 C4：符号合规判定的四类差异

**这是十几轮踩坑归纳的核心区分**：

| diff_type | 含义 | 处理 | 判定 |
|---|---|---|---|
| `CODEPOINT` | 码位不同语义同（Ø/φ/⌀、↓/↧、×/*） | **等价类归一** | PASS |
| `WHITESPACE` | 空格差异（`Ø60 js6` vs `Ø60js6`） | 正则解析 | PASS |
| `SEPARATOR` | 分隔符差异（`/` vs 空格 vs `^`） | 三元组归一 | PASS |
| `LATEX` | LaTeX 命令（`\psi`/`\downarrow`） | 映射 | PASS |
| **`SYMBOL_LOST`** | **语义符号丢失（`Ø80`→`80`）** | 🔴 **不可归一** | **FAIL** |
| **`VALUE_ERROR`** | 数值错误（28 读成 26） | 🔴 不可归一 | **FAIL** |
| `SEMANTIC` | 语义不同（深度 vs 埋头孔） | 🔴 需形态核实 | PENDING |

> 此表的PASS/FAIL仅描述有证据支持的读取或语义比较，不是图纸合规结论。前四类仅在对象、位置和上下关系已核准时可比较；符号丢失及数值变化必须区分机器读错与图纸实际差异。
> **混为一谈 = 误报。**

**与五层体系印证**：`symbol_loss` 独立出现在 L3 四分类中——两条路径互不知情地撞上同一结论。

## 5.2 符号字典与OCR混淆候选分离

| 类别 | 示例 | 使用边界 |
|---|---|---|
| 明确编码事实 | ⌀U+2300为DIAMETER SIGN；∨U+2228与∧U+2227是不同字符 | 码位名称不自动证明图面工程语义 |
| 受限语义比较 | Ø/φ等在已确认直径语境中作为候选 | 保留原字形；语义一致不等于规范形态合格 |
| OCR混淆候选 | ψ、0、∅等可能与直径图形混淆 | 只能触发回看原图，禁止无条件改为直径 |
| 专业形态待核 | 深度、沉孔、埋头孔、弧长、斜度、锥度 | 核对标准原页、字形及对象关系后再发布映射 |
| LaTeX转录 | `\psi`、`\vee`、`\pm`等 | 只说明转录输出的字符，不能反证标准原文采用该命令 |

此前从识读结果得到的`\psi`尚不足以证明标准把ψ定义为直径，不进入已确认字典。所有未核形态保持PENDING，须用原页裁图、条款/图号、审核人和版本核准。

字典区分“编码别名、OCR混淆候选、标准形态”，分别输出读取状态、语义比较状态和规范符合性。禁止通过归一化消除图纸真实缺符号、H/h差异或上下偏差差异。

## 5.3 归一化规则

```
canonical = (基本尺寸, 上偏差, 下偏差, 标注类型, 孔或轴)

Ø142 +0.028/+0.003  → (142.0, +0.028, +0.003, 极限偏差, ?)
Ø142 +0.028 +0.003  → (142.0, +0.028, +0.003, 极限偏差, ?)   ← 归一后相同
Ø60 js6             → (60.0, +IT6/2, -IT6/2, 公差带代号, 轴)
```

**解析三条铁律**：
1. **不按空格分词**（`60+0.03` 无空格会断），用正则或 `+/-` 锚点
2. **偏差必带符号**：正值补 `+`、负值留 `-`、**零写 0 不加符号**
3. **js 不可拆**（`js` 是双字母对称公差，拆成 j6/s6 全错）

**基本偏差代号封闭集**（GB/T 1800.1 表 4）：
```
a b c cd d e ef f fg g h js j k m n p r s t u v x y z za zb zc
双字母 7 个：cd ef fg js za zb zc   禁用：I i L l O o Q q W w
```

> **这是可 100% 枚举的封闭集**，与"机械符号是开放集"不矛盾——公差代号是特例。

# 第六部分　案例库：系统的成长机制

## 6.1 为什么案例库是护城河

> **模型谁都能调，案例库是独有的。**
> 行业共识：工程图纸最缺**配对数据**（扫描件+精确 DXF），只有加工厂才有。
> T01—T05有五组正误PDF任务素材；CAD源中目前只识别到九组标题栏，T03正确变体尚未核准。PDF配对标签不证明CAD配对完整或全部专业标签正确。

## 6.2 分类维度

```
行业 → 零件类型 → 特征 → 错误类型
MECH/ELEC/ARCH
 └ DISK 盘套 / SHAFT 轴 / BOX 箱体 / FORK 叉架 / STD 标准件
    └ HOLE/SHAFT_F/THREAD/KEY/CENTER/CHAMFER/SECTION/DIM/GTOL/SURF
       └ SYM/LTYPE/TOL/MISS/REDUN/VIEW/ANNO
```

**ID 编码**：`CASE-{IND}-{PT}-{FT}-{ET}-{序号}`

## 6.3 🔴 语境字段（必须显式记录）

**T03-1 教训**：同一判据在不同语境下**结论相反**。

| 语境 | 编码 |
|---|---|
| 图纸性质 | `CTX-ASSEM` 装配图 / `CTX-PART` 零件图 |

| ③ 录入员 | 填字段、入库 |

| 闸 | 内容 |
|---|---|
| 闸1 | 依据分型核准：国标需条款及版本，经验需来源和审核；适用条件成立 |
| 闸2 | 形态人工核实（`↓` vs `∨` 教训） |

**闭环**：AI 判 → 专家纠 → 案例入库 → 下次命中。专家审核既有工时成本，也形成可复用资产。

### 9.1.1 产品验收补充口径

- 单图规范审查与参考答案对照分别测试；解释与改进校验其依据和建议，不把说明覆盖率当解释正确率。
- PDF-only与CAD增强、自动结果与人工闭环分别统计；问题级精确率、召回率、定位、规则适用、证据有效性、解释忠实性、无法判定率、人工量共同报告，数值门槛由首轮基线与客户冻结。
- T01—T05可继续用于提炼规则和回归；独立验收按零件/图纸来源/模板划分新图，避免同源变体在检索库与独立测试间泄漏。
- 正常图误报为0仅描述已测集合，不外推为总体零误报；重复重跑衡量稳定性，不等于泛化保证。
