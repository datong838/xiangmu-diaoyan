## 本方案解决什么

按“来源类别S × 知识职责D × 对象/任务 × 条件/版本”组织资料；国标讲适用要求，教材讲对象/表达和原理，手册讲有工况的方法与工艺，正误图册讲差异、原因和改进，数据集补几何/文字/视图样本。它们围绕真实问题联合使用。

工程主线是任务与范围 → 图面事实/质量 → 表达语义 → 对象关联 → 工程情境 → 待查问题 → 适用条件/例外 → 判据/方法 → 分型结论 → 解释 → 改进 → 复检。J0—J11可回退或跳过，不是12道审批，也不意味着每问调用12次模型。

全量原件和细节保留在可定位目录与磁盘索引；约100MB是热点导航预算，不是1TB知识的无损压缩。相关1GB是证据集合，不是每问整体喂模型。Q0/Q1秒级目标仍须按规模与质量验收；OCR、复杂计算和改图复检另计。
