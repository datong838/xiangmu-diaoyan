# 工程知识库方案重构与自审记录

日期：2026-10-16；KB-DESIGN-002；探索草案。上一版存于[001历史版本](../KB-DESIGN-001/README.md)，只为比较，不构成修改限制。

## 1. 用户方向与本轮结果

用户强调：知识既按国标/教材/手册/正误图册/经验等领域组织，也沿“图面事实→对象关联→适用条件→判据执行→解释与改进”参与任务；希望补全遗漏，建设独特工程知识库。用户进一步明确：这些文档均由同一助手探索编写，不存在固定权威文档或门禁，允许重构。

本轮据此调整为**知识组织轴S/D/对象任务/条件版本 + 工程使用轴J0—J11 + K0—K5大容量存储底座**。D/J不是已证实标准，也不是固定本体和审批流程，需要真实样例检验并可随时修改。

## 3. 对遗漏的补全与取舍

| 容易遗漏 | 本轮设计 |
|---|---|
| 不知道任务是读图、对照还是规范/工艺判断 | J0任务与范围；知识/结论按类型区分 |
| 没识别到就当图上缺少 | J1质量/范围，缺失与未知分开，补查其他表达位置 |
| 认出符号却不懂表达 | J2语义与单位，原字形和解释分列 |
| 认出孔和H7却未确认附着 | J3关系独立建模与扰动验证 |
| 从图形猜功能/材料/设备 | J4图外条件与来源/假设分开 |
| 只检索支持“有错”的片段 | J5问题假设与正常/边界对照 |
| 前提、例外或来源冲突被忽略 | J6三值条件与独立冲突状态 |
| 找到方法等于算过 | J7能力单元/工具/MethodRun分开 |
| 所有结果合成PASS/FAIL | J8读取、参考、规范、工程建议分型 |
| 引用条款但原因无关 | J9支持关系与反证解释 |
| 改法唯一、只优化局部 | J10约束、替代、影响范围 |
| 提完建议就记成功经验 | J11改前后复检及经验边界 |

没有宣称12步穷尽工程认知：实际材料可暴露新步骤/关系；术语问答也无需跑全链。图片资料对多样性、识别与检索仍重要，不能用“反对堆图”否定图像建设本身。

## 5. 仍需要实际探索的内容

- D/J粒度是否合适、哪些方法值得复用、如何表达关联与例外，需要真实主题验证。
- 工程知识提炼、关联算法、精排/图像模型、条件求值与改图复检都未实现。
- 图外条件不全时，如何给出有用但不越界的建议，需要业务实例与专家/现场证据。
- 同题按缺口检索相对普通相似检索的收益、成本和时延未测。
- 1TB原件的模态/对象分布、索引和方法记录实际占用、备份与恢复待盘点。
- 原目标态的历史实验、标准原页和数据集专业标签本轮没有复现实证。

资料全面保留与登记、GB级磁盘索引、约100 MB导航工作集仍是工程方向；秒级仍指有界定位/证据包，不承诺完整整图审查或1GB深读都在相同时限完成。

## 6. 推荐接续

先看10、11、12，然后选一个真实主题：整理教材/标准/手册/对照中的相关内容，沿J链演练正常、错误、边界、未知和改后情况；再修订分类、字段和检索策略。W0全量登记可并行，重语义计算和TB级扩容随后渐进。

目标是获得一条真实能走通、能解释且能被反例修正的工程判断链，而不是先把全部表格填满。
