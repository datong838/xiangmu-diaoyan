# W9-4B 业绩分类、材料用途与重复控制验证记录

> 日期：2026-10-18　状态：合成环境验证通过；下一步 W9-4C。

## 1. 本波验证结论

W9-4B 已把 T06 从业务条款落实为可运行的成果候选办理链。教师或负责人只能从至少一份已保存材料建立成果候选；专业群助手的分类和指标支撑只作为建议；负责人必须逐条作出接受、修改、拒绝或待核实决定。所有决定均明确返回“指标进度未变化”。

本波不把 D 企业的“待开展”误写成成果。D 没有洽谈记录和材料，建立空成果候选会被拒绝，待开展事实继续由 W9-4A 任务链承载。

## 2. 已实现的产品对象

| 对象 | 已验证行为 |
|---|---|
| 成果候选 | 保存业务日期、专业、来源任务、建议分类和建议理由 |
| 材料用途 | 同一成果可关联主证据、补充证据和过程材料，原版本均保留 |
| 指标支撑建议 | 指向已发布的正式指标知识，保存建议、理由和人工决定 |
| 分类决定 | 支持接受、修改、拒绝和待核实，决定后不能被第二次覆盖 |
| 重复材料组 | 至少两份已关联材料可被标记为同一成果的不同载体；确认不删除文件 |
| 建设账本与回执 | 所有写操作保留操作者、范围、幂等键、对象、结果和对账地址 |

## 3. A、B、C、D 验证结果

- **A 企业**：正式协议扫描件、电子版和活动记录共三份材料形成“本年度已完成”候选；扫描件与电子版被确认为同一成果的重复材料组，三份原材料仍全部存在；指标支撑建议经负责人确认，但指标值没有变化。
- **B 企业**：助手误建议“本年度已完成”后，负责人可修改为“本年度推进中”，指标支撑保留为待核实。
- **C 企业**：2025 年协议被确认为历史成果，对“2026 年新增合作企业”指标的支撑建议被拒绝。
- **D 企业**：零材料请求返回校验失败，数据库不存在 D 企业成果候选。
- **补充状态**：另用合成材料验证成果整体“待核实”和“拒绝”，保证四类人工决定均真实执行。

## 4. 权限与防覆盖结果

- 专业教师可发起和查看本专业成果，不能查看其他专业成果；
- 专业群负责人可发起和决定；教务审核人员只读；信息支持人员得到空列表且不能读取详情；
- 相同幂等键重放返回同一回执，不新增成果或决定；
- 已决定候选使用新操作再次决定返回版本冲突；
- 指标支撑决定与成果分类决定在同一事务内完成，不能只处理其中一部分；
- 重复材料确认不合并、不删除、不覆盖材料版本。

## 6. 风险和下一步

当前只使用合成材料，分类规则、材料充分性和学校实际口径仍需在 W10 用获准样例验收。W9-4B 仅固定人工确认后的成果事实和支撑关系，不产生指标正式值。

下一步 W9-4C 应固定指标规则版本、统计期间、去重键、证据门槛、输入快照和截止点，先产生可重复计算的候选结果，再由负责人确认进度与差距。A 的扫描件和电子版必须只贡献一个业务成果；B、D 应形成不同差距原因。
