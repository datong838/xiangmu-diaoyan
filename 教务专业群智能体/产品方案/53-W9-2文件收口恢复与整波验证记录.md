# W9-2 文件收口、恢复与整波验证记录

> 版本：v1.0　日期：2026-10-18　状态：W9-2 合成环境整波通过。  
> 方案依据：第 40、42、48、51、52 份方案与记录。  
> 结论边界：证明合成身份、合成材料和本地学校侧目录下的 W9-2 能力；不等同于学校真实身份、正式对象存储或 W10 试点验收。

## 1. 收口能力

### 1.1 只读文件核对

`file:audit` 对数据库全部 `material_blob` 与学校侧目录逐项核对：存储键、存在性、字节数和 SHA-256，同时识别未登记文件、暂存残留、软链接和越界存储键。命令不输出业务标题、原始文件名或文件正文；发现任一偏差时退出非零。

### 1.2 显式孤儿清理

`file:cleanup-orphans` 只有在提供明确确认值和正数保留时间后才运行。清理前先核对已登记文件；已登记文件缺失、损坏、路径异常或目录存在软链接时整次清理拒绝。命令只删除超过保留时间的未登记文件和暂存残留，随后自动复核。

### 1.3 跨学校重复隔离

重复提示查询始终带 `school_id`。两所合成学校登记字节完全相同的文件时，两校首次登记均返回 `possibleDuplicate=false`；同校第二次登记相同内容返回 `true`。双方使用已知材料编号互相访问均返回不存在。

## 2. 异常与清理验证

| 场景 | 结果 |
| --- | --- |
| 干净目录 | 4 个登记原件、4 个实际文件，零异常 |
| 删除登记文件 | 报告缺失文件 |
| 同字节数篡改 | 报告 SHA-256 不一致 |
| 新增未登记文件 | 报告孤儿文件 |
| 新增 `.staging` 残留 | 报告暂存残留 |
| 新增软链接 | 报告软链接并拒绝清理 |
| 未提供清理确认值 | 命令拒绝执行 |
| 未超过保留时间 | 文件保留 |
| 超过保留时间 | 只删除孤儿和暂存残留 |
| 清理后复核 | 4 个登记原件全部保留，零异常 |

## 3. 隔离恢复验证

源环境包含：

- 2 所学校、2 个专业群、5 个专业；
- 4 个材料、5 个材料版本、4 个原件；
- 18 条建设账本、7 条安全事件。

执行 PostgreSQL 完整备份和学校侧文件目录复制，恢复到新的数据库与新的文件目录。恢复后：

| 核对项 | 源环境 | 恢复环境 | 结果 |
| --- | ---: | ---: | --- |
| 学校 | 2 | 2 | 一致 |
| 专业群 | 2 | 2 | 一致 |
| 专业 | 5 | 5 | 一致 |
| 材料 | 4 | 4 | 一致 |
| 材料版本 | 5 | 5 | 一致 |
| 原件 | 4 | 4 | 一致 |
| 建设账本 | 18 | 18 | 一致 |
| 安全事件 | 7 | 7 | 一致 |

恢复库再次执行迁移检查通过；账本前后摘要断链数为 0；4 个原件重新计算字节数和 SHA-256 均一致；教师能在恢复环境列出本人 2 个材料并通过单次凭证读取当前版本；同一材料的 2 个历史文件版本均重新读取和校验通过。

恢复验证结束后，源库计数仍为原值，源文件目录核对仍为 4/4、零异常，证明恢复测试没有反写源环境。
