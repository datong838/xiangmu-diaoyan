## 1. 审计结论

W9-8C 已经形成可运行的数据、权限、文件、知识、任务、指标、智能体、成果、恢复与候选证据链，证明后端业务能力可以在合成环境中运行。正式工程当前没有 `apps/web`，学校教师、专业群负责人和审核人员尚无可使用的正式工作台。

因此，`W9-8C-candidate.1` 的准确状态是：**后端与候选资料基线，可以进入正式工作台集成；不是可直接交给学校开展真实业务试点的完整产品。** W10-A 空白资料包仍然有效；W10-B 真实环境初始化必须等待 W9-9 正式工作台达到试点门槛。

本次审计不否定 W9-0 至 W9-8C 的运行证据，也不重做已经通过的业务服务。它补齐产品使用层，并把候选状态恢复到与事实一致的范围。

## 2. 正式工作台的产品责任

正式工作台需要把现有接口组织为教师和教务人员可连续办理的产品，而不是接口演示器。它必须做到：

1. 显示当前学校、专业群、建设周期和当前角色，避免在错误范围内办理；
2. 围绕建设对象提供查看、填写、提交、修改、退回、确认、审核和回查入口；
3. 所有写入使用服务端要求的范围、当前版本、幂等键、人工决定和操作回执；
4. 把目标、任务、人员、材料、证据、进度、成果和历史关系呈现在对象办理页；
5. 专业群智能体使用同一批正式对象和权限，协助查询、整理、形成草稿和继续办理；
6. 页面刷新后从数据库重新读取状态，不依赖浏览器本地业务状态；
7. 无权、空数据、冲突、失效、失败、结果未知和能力关闭均有明确页面状态；
8. 页面文字采用学校教师能够理解的业务表达。

## 3. W9-9 分段

### 3.1 W9-9A：正式壳层与任务首链

建立正式 `apps/web`，实现：

- 候选环境进入页：填写服务地址、会话凭证和工作范围；凭证只保存在当前浏览器会话；
- 顶部工作范围：当前专业群、建设周期和当前角色；
- 建设总览：读取本人信息、专业群详情、运行总览和任务列表；
- 计划与任务：任务列表、任务详情、新建任务；
- 写入回执：显示对象编号、对象版本、操作编号和下一步，不以弹窗“成功”代替可核对记录；
- 加载、空白、无权、失效、冲突和一般错误状态；
- 视觉与交互沿用已经评审的 4181 原型骨架，但所有业务事实来自正式 API。

W9-9A 只建立任务首链，不把尚未接入页面的材料、指标、报告和智能体能力伪装成已可操作。导航可以标出后续工作区，但不可返回假数据或假成功。

### 3.2 W9-9B：建设依据、资料与专业群知识库

接入三类建设依据、材料版本、资料吸收、候选条款、人工确认、正式知识检索和来源追溯，承接 T01、T03、T05，并为 T02、T04 提供底座。

### 3.3 W9-9C：工作、指标、差距与专业群智能体

接入工作记录、材料提交、退回补充、成果分类、指标计算与确认、差距任务，以及智能体任务知识包、办理计划、人工确认、动作回执、暂停和恢复，承接 T04、T06—T12。

### 3.4 W9-9D：成果编制、审核、归档与试点门槛

接入周期总结、学校模板、成果编制、引用、缺项、局部改稿、独立审核、正式导出、归档、实践案例和多专业群切换；完成四角色浏览器验收、权限负向、异常恢复和 W10 现场进入门槛，承接 T09、T12—T14、T17、T18。T15/T16 继续关闭。

## 4. W9-9A 页面与接口

| 页面 | 真实输入 | 可执行动作 | 可核对结果 |
| --- | --- | --- | --- |
| 进入工作台 | API 地址、会话凭证、学校/专业群/周期范围 | 验证会话并保存当前会话设置 | 当前人员、角色和范围 |
| 建设总览 | `/me`、专业群详情、运行总览、任务列表 | 进入任务或切换范围 | 数量、状态、更新时间和明细入口 |
| 任务列表 | 当前范围与任务筛选 | 查看任务、新建任务 | 服务端任务集合与空白状态 |
| 任务详情 | 任务稳定编号 | 查看当前版本、责任人、材料要求和历史入口 | 当前版本和关系摘要 |
| 新建任务 | 正式知识条目、责任人、确认人、日期、材料要求 | 形成任务草稿或正式创建 | 操作编号、对象编号、新版本 |

候选环境进入页只解决当前没有学校统一身份接入的问题。它不新建账号、不绕过服务端权限、不在源代码中写入固定令牌，也不代表 W10 的正式登录方式已经确定。

8. 浏览器完成从进入工作台到新建任务并回查的真实首链；

10. 验证记录明确说明 W9-9A 只完成任务首链，不能替代 W9-9B—D 和 W10。

## 7. 停止与回退规则

- 页面需要改变已封板 API 语义时，停止编码并先补接口方案；
- 页面为了展示而写死业务对象或成功结果时，停止并改为真实读取或明确空白状态；
- 写入结果未知时不自动重复提交，只展示操作编号和对账入口；
- 发现越权标题、数量、摘要或文件名泄露时停止本段验收；
- 后端累计测试出现回归时先恢复兼容，不能通过降低既有门槛完成页面；
- W9-9A 可整体删除 `apps/web` 回退，不影响既有数据库和后端运行链。
