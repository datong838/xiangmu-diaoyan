# 专业群 AI 工作站核心对象与关系详细设计

> 版本：v1.0　日期：2026-10-18　状态：内部评审稿。  
> 对应波次：W1、W2。  
> 文档职责：定义系统实际管理的对象、对象之间的关系及必须保持的约束，为页面、知识库、智能体和数据设计提供共同语言。

## 1. 设计结论

专业群 AI 工作站不能以“文件夹 + 聊天框”作为产品骨架。产品骨架由三部分构成：

1. **建设对象**：专业群建设中真实存在、会持续变化的学校、专业、依据、指标、任务、工作、材料、证据和成果；
2. **建设关系**：这些对象之间“属于、来源于、分解为、负责、支撑、引用、替代、冲突、影响”等关系；
3. **建设记录**：谁在何时提交、修改、确认、退回或审核了什么，以及当时依据的对象版本。

文件是对象之一，不是全部。智能体回答、进度判断和报告文字都必须建立在对象与关系之上。

## 2. 对象分层

| 层级 | 对象类别 | 核心问题 |
| --- | --- | --- |
| O0 范围层 | 学校、部门、专业群、专业、建设周期 | 这条信息属于哪里、适用什么时间 |
| O1 人员层 | 人员、岗位、角色、责任关系、授权 | 谁能看、谁能写、谁负责、谁确认 |
| O2 依据层 | 依据文件、文件版本、原文条款、口径决定、冲突 | 为什么这样建设和判断 |
| O3 目标层 | 建设事项、目标、指标、分期目标、统计规则、证据要求 | 要达到什么、怎样才算达到 |
| O4 执行层 | 计划、任务、子任务、工作记录、问题、补充任务 | 谁在何时完成什么工作 |
| O5 资料层 | 原始材料、材料版本、资料包、材料用途、候选关系 | 有哪些原始资料、来自哪里、怎样使用 |
| O6 事实证据层 | 事实陈述、成果、证据关系、计算结果、进度判断 | 已经发生什么、由什么支持、结论是什么 |
| O7 成果层 | 模板、模板版本、成果编制任务、章节、草稿版本、引用、导出件 | 怎样形成正式可交付结果 |
| O8 过程保障层 | 智能体任务、建议、人工决定、审核记录、操作记录、后台任务 | 系统和人怎样共同完成、怎样追溯 |

## 3. 对象通用字段

除原始二进制内容外，每个核心对象至少具备：

| 字段 | 含义 |
| --- | --- |
| 对象编号 | 全局稳定编号，不因改名或移动而变化 |
| 对象类型 | 用于区分专业、指标、任务、材料等 |
| 学校范围 | 对象所属学校 |
| 专业群范围 | 对象所属专业群；校级对象可为空 |
| 专业范围 | 对象所属专业；群级对象可为空或关联多个专业 |
| 建设周期 | 对象适用的年度、项目期或阶段 |
| 当前状态 | 对象当前业务状态 |
| 当前有效版本 | 当前被采用的版本编号 |
| 可见范围 | 谁可以查看正文、摘要和存在性 |
| 责任主体 | 当前负责人员或组织 |
| 创建与更新时间 | 记录生成和最后变化时间 |
| 来源方式 | 人工创建、材料拆解、导入、智能体建议或其他来源 |
| 确认状态 | 未确认、部分确认、已确认或已失效 |

对象编号和版本编号分开：对象编号回答“是不是同一件事”，版本编号回答“看到的是哪一次内容”。

## 4. 核心对象目录

### 4.1 范围与组织对象

| 对象 | 产品用途 | 关键约束 |
| --- | --- | --- |
| 学校 | 最上层资料权利与组织范围 | 学校资料不能归入服务方自有数据范围 |
| 部门 | 教务、学院及其他责任单位 | 采用学校真实组织关系，不预设固定层级 |
| 专业群 | 建设、知识和权限的主要工作范围 | 每个专业群保持独立事实、任务、进度与成果 |
| 专业 | 专业群中的核心或支撑专业 | 一个专业在不同周期的群关系可变化 |
| 建设周期 | 项目期、年度、阶段或统计截止点 | 查询和判断必须明确周期 |
| 人员 | 教师、教务、负责人、审核人等 | 人员本身与其当前角色分开管理 |
| 角色 | 决定可执行的产品动作 | 角色不自动获得所有业务正文权限 |
| 责任关系 | 人员对对象承担的职责 | 必须记录适用时间和确认来源 |

### 4.2 建设依据与目标对象

| 对象 | 产品用途 | 关键约束 |
| --- | --- | --- |
| 依据文件 | 申报书、建设任务书、实施方案及后续正式文件 | 同一文件可有多个版本 |
| 文件版本 | 保存原件、批准状态、生效时间和内容定位 | 已被引用的版本不得被覆盖 |
| 原文条款 | 从具体版本的章节、表格或单元格形成定位 | 条款文本必须回到原始版本位置 |
| 建设事项 | 把多份文件中的相关要求组织为同一事项 | 关系由负责人确认 |
| 目标 | 建设期或年度要实现的方向与结果 | 目标不能仅由材料数量代替 |
| 指标 | 可判断的建设要求 | 需绑定统计规则和证据要求 |
| 分期目标 | 指标在年度、阶段的目标值 | 保留来源和适用期 |
| 统计规则 | 对象范围、时间范围、去重和计算方法 | 采用确定性计算；变更形成新版本 |
| 证据要求 | 判断指标时需要的材料类型和确认条件 | 材料存在不等于已满足要求 |
| 口径冲突 | 多份依据或规则之间不一致 | 未处理前不能由智能体自行选用 |
| 口径决定 | 获授权人员对冲突的正式处理 | 记录决定人、原因、生效范围和时间 |

### 4.3 执行与日常工作对象

| 对象 | 产品用途 | 关键约束 |
| --- | --- | --- |
| 计划 | 年度、月度、周度安排 | 计划调整保留前一版本 |
| 任务 | 对人员可办理的工作单元 | 必须有责任、节点、预期产出和来源 |
| 子任务 | 对任务的可执行拆分 | 完成状态不自动等同上级目标达成 |
| 工作记录 | 教师或教务对真实工作的持续说明 | 业务日期与上传日期分开 |
| 问题 | 工作、材料、口径或进度中的待处理事项 | 不能只用备注代替闭环状态 |
| 补充任务 | 对差距形成的正式后续行动 | 只有确认后才进入执行清单 |
| 退回意见 | 说明为什么退回以及需要怎样修改 | 与被退回版本绑定 |

### 4.4 资料、事实和证据对象

| 对象 | 产品用途 | 关键约束 |
| --- | --- | --- |
| 原始材料 | 文件、图片、聊天摘录或工作说明的登记对象 | 原件不可被整理结果覆盖 |
| 材料版本 | 保存每次补充或替换的实际内容 | 新版本不改变历史引用 |
| 资料包 | 一次交接或一次任务选择的一组材料 | 记录选择时的版本快照 |
| 事实陈述 | 从已确认工作或材料中形成的结构化事实 | 与智能体推断、建议分开 |
| 成果 | 经确认的建设产出或业绩 | 需有唯一性与归属范围 |
| 证据关系 | 某材料版本怎样支持某事实、成果或指标 | 记录用途、充分性和确认人 |
| 重复组 | 可能为同一事实或成果的多个对象 | 人工决定合并或分别保留 |
| 进度计算结果 | 按规则计算的数值和明细 | 固定数据截止点和规则版本 |
| 进度判断 | 达成、未达成、资料不足或待确认 | 自动建议与正式结论分开 |

### 4.5 正式成果与过程对象

| 对象 | 产品用途 | 关键约束 |
| --- | --- | --- |
| 模板及版本 | 定义最终成品的结构、栏目和格式 | 不同成果类型各自管理版本 |
| 成果编制任务 | 组织报告或申报材料的编写过程 | 固定模板、期间、截止点和输入快照 |
| 章节 | 可独立编写、修改和审核的成果部分 | 与引用和人工保护范围关联 |
| 草稿版本 | 保存每轮生成或人工修改结果 | 新稿不覆盖基版本 |
| 引用 | 报告内容与事实、材料、计算结果的联系 | 正式数字必须可回查 |
| 审核记录 | 提交、退回、批准和重审 | 审核人必须独立且有权 |
| 导出件 | Word、PDF 或其他正式成品 | 绑定批准版本和生成时间 |
| 智能体任务 | 一次查询或办理过程 | 绑定用户、范围、目标、输入和业务对象 |
| 智能体建议 | 分类、关系、任务、文字或判断建议 | 未确认前不能成为正式事实或决定 |
| 人工决定 | 对关系、口径、任务、进度或成果的确认 | 记录决定内容和影响范围 |
| 操作记录 | 所有关键读写与审批动作 | 不随对象删除而丢失 |

## 5. 关系目录

### 5.1 结构关系

| 关系 | 起点 → 终点 | 说明 |
| --- | --- | --- |
| 隶属于 | 部门/专业群/专业 → 上级组织 | 采用真实组织关系 |
| 组成 | 专业 → 专业群 | 标明核心、支撑或其他关系及有效期 |
| 参与 | 人员 → 专业/专业群/任务 | 区分参与和负责 |
| 负责 | 人员/部门 → 对象 | 可指定主要和协同责任 |
| 适用于 | 依据/规则/模板 → 范围与周期 | 防止跨群、跨期误用 |

### 5.2 依据与分解关系

| 关系 | 起点 → 终点 | 说明 |
| --- | --- | --- |
| 来源于 | 条款 → 文件版本 | 必须带原文定位 |
| 归入 | 条款 → 建设事项 | 可先作为候选再确认 |
| 要求 | 建设事项/条款 → 目标或指标 | 说明建设要求 |
| 分解为 | 目标/指标/计划 → 下级目标或任务 | 保留上下游链路 |
| 采用 | 指标 → 统计规则/证据要求 | 必须指向具体版本 |
| 冲突于 | 条款/规则 → 条款/规则 | 不因冲突而删除任一来源 |
| 由其解决 | 口径决定 → 口径冲突 | 决定可影响多个下游对象 |

### 5.3 执行与证据关系

| 关系 | 起点 → 终点 | 说明 |
| --- | --- | --- |
| 执行 | 工作记录 → 任务 | 说明本次工作对应什么任务 |
| 产生 | 工作记录/任务 → 材料或成果 | 区分过程材料和正式成果 |
| 支持 | 材料版本 → 事实/成果/指标 | 需记录支持程度与确认状态 |
| 证明 | 证据关系 → 事实或成果 | 正式使用需经人工确认 |
| 计入 | 成果 → 指标 | 受统计范围、时间和去重规则限制 |
| 发现 | 进度判断 → 问题 | 记录问题来源 |
| 转为 | 建议动作/问题 → 补充任务 | 只有确认后生效 |
| 替代 | 新材料版本/新决定 → 旧版本/旧决定 | 旧对象保留并标记失效 |

### 5.4 成果与追溯关系

| 关系 | 起点 → 终点 | 说明 |
| --- | --- | --- |
| 使用 | 编制任务 → 模板版本/输入快照 | 固定本次产出条件 |
| 引用 | 章节/草稿 → 事实、材料或计算结果 | 支持来源回查 |
| 修改自 | 新草稿版本 → 基版本 | 保存差异和修改要求 |
| 审核 | 审核记录 → 草稿版本 | 退回或批准必须绑定具体版本 |
| 导出自 | 导出件 → 已批准草稿版本 | 禁止从未批准稿生成正式件 |
| 影响 | 依据/规则/事实版本变化 → 下游对象 | 形成待复核清单，不自动改写正式结果 |

## 6. 关系的产品状态

关系本身也必须管理状态：

| 状态 | 含义 | 能否参与正式统计或报告 |
| --- | --- | --- |
| 候选 | 人工或智能体提出，尚未确认 | 否 |
| 待补充 | 关系方向可能正确，但缺依据或范围 | 否 |
| 已确认 | 获授权人员确认，可正式使用 | 是 |
| 被拒绝 | 已明确不成立 | 否，但保留判断记录 |
| 已失效 | 曾成立，因版本或周期变化不再适用 | 历史可查，当前不使用 |
| 有冲突 | 同时存在相互不一致的有效来源 | 暂停形成正式结论 |

## 7. 原件、事实、建议、决定和结果的边界

```text
原件/原始说明
  → 提取内容
  → 候选事实与候选关系
  → 人工核对
  → 已确认事实与关系
  → 规则计算或内容编制
  → 建议结论/成果草稿
  → 人工判断或审核
  → 正式决定/正式成果
```

- 原件证明“系统收到了什么”，不直接证明业务事实成立；
- 提取内容是机器可处理的中间结果，不等于人工确认；
- 智能体建议说明“系统建议怎样理解或处理”，不能替代负责人决定；
- 人工决定必须绑定当时看到的对象版本和范围；
- 正式成果引用已确认事实，但不能反向修改源事实。

## 8. 不可破坏的关系约束

1. 任何正式指标结论必须指向统计规则版本、数据截止点和已确认事实。
2. 任何正式报告数字必须能够回到进度计算结果或已确认事实。
3. 材料被审核通过，不表示它自动对所有成员可见。
4. 任务完成，不表示指标自动达成。
5. 材料存在，不表示证据充分。
6. 同一成果多份文件不能因文件数量重复计数。
7. 新版本不能改写旧版本上的历史引用。
8. 智能体建议不能直接成为负责人确认、审核批准或正式发布。
9. 跨专业群只能复用结构、模板和方法；事实、人员、权限、进度和成果必须独立建立。
10. 删除业务对象时，相关操作记录、审核记录和历史关系仍需按规定保留。

## 9. T01—T18 对对象关系的使用

| 任务组 | 主要读取 | 主要创建或更新 |
| --- | --- | --- |
| T01—T05 | 范围、人员、原始材料、依据文件 | 材料版本、工作记录、组织关系、条款、目标、指标和候选关系 |
| T06—T08 | 建设依据、成果、指标、计划 | 指标匹配、任务、工作进展、问题和人工确认 |
| T09—T11 | 计划、任务、工作、事实、证据、指标 | 总结、进度判断、差距、建议动作和补充任务 |
| T12—T14 | 已确认事实、关系、计算、模板和历史成果 | 查询结果、编制任务、草稿版本、引用、修改和审核记录 |
| T15—T17 | 复用任务、材料、证据和审核对象 | 对应选配业务的专用字段和关系 |
| T18 | 结构、模板、能力和初始化规则 | 新专业群的独立范围、依据、人员、权限和知识关系 |

## 10. 评审问题

1. 学校、部门、学院、专业群和专业的真实层级及跨属关系；
2. 一个专业能否同时参与多个专业群及其时间范围；
3. 哪些对象由教师确认，哪些必须由专业群负责人或校级人员确认；
4. 正式成果、业绩和证据的唯一性规则；
5. 资料正文、摘要、存在性和统计结果是否需要分层授权；
6. 口径决定的正式确认人及生效范围；
7. 历史对象的保存期限和学校导出要求。
