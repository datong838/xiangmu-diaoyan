# W9-7B2 八入口跨群隔离与独立变化验证记录

## 1. 本次验证回答什么

本次验证使用同一名负责人同时管理同一学校内的源专业群和新专业群。源群建立专属材料、正式知识、任务、智能体任务、报告模板、成果编制、PDF 导出和账本操作；目标群建立自己的三类建设依据、正式知识、指标规则和报告模板。随后所有正式入口都带学校、专业群和建设周期，使用目标范围直访源对象必须被拒绝或返回零项。

它证明合成环境中的接口和数据库关系能够隔离两个专业群，不代表学校真实第二专业群已经建立，也不代表真实身份提供方、真实学校资料或外部智能服务已经接入。

## 3. 产品内核查

系统新增不可变隔离核查记录，固定初始化编号、启用时的初始化版本、源群、目标群、核查人和八项结果。核查由服务端查询现有关系并计算交叉引用数，调用方不能提交“通过”。本次八项交叉引用数均为 0，结果为 `passed`。

自动验收程序把上述八个正式接口探针的预期值、实际状态码或数量及摘要写入同一核查编号。核查结果、八项明细和探针记录均验证为不可修改、不可删除。

## 4. 独立变化验证

1. 源群报告模板从第一版升级到第二版后，目标群报告模板仍指向原来的目标版本；
2. 完成全部源群写入后，把源群状态改为归档，目标群仍为 `active`；
3. 同一名负责人在两个群拥有两条明确范围的授权，接口没有根据“同一个人”合并两群资料；
4. 源群继续产生报告导出和模板版本时，目标群统计与账本没有增加源群对象。
