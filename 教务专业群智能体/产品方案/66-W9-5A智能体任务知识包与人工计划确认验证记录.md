# W9-5A 智能体任务、知识包与人工计划确认验证记录

> 日期：2026-10-18　状态：合成环境验证通过；下一步 W9-5B。

## 1. 验证结论

专业群智能体已经从页面概念进入可运行产品对象。一次用户请求会形成稳定的智能体任务、任务版本、固定知识任务包、可检查计划和人工决定。智能体使用发起人的现有权限，不能借“助手”身份扩大范围；含草稿写入的计划未经负责人批准不能进入执行阶段，批准计划也不会直接建立、派发或完成业务任务。

本轮没有接入外部生成模型。测试通过调用方提供的确定性结构化意图验证任务协议，因此不能据此宣称开放式自然语言理解已经完成。

## 2. 已验证产品行为

| 行为 | 结果 |
|---|---|
| 指标进度请求 | “查一下 2026 年新增合作企业指标现在完成多少”形成任务，知识包固定规则版本、计算运行、正式进度、差距和截止点 |
| 只读计划 | 指标进度和本人任务查询直接进入 `ready_to_execute`，步骤均为只读，不替负责人确认进度 |
| 差距后续计划 | B、D 两类差距形成不同的读取、任务草稿准备和草稿建立步骤，停在 `waiting_plan_confirmation` |
| 人工计划决定 | 只有专业群负责人可批准写候选计划；批准后进入待执行，回执明确 `businessActionExecuted=false` |
| 不支持意图 | “直接替我批准并对外提交申报书”保留原请求，停在 S3 并说明尚未进入首批动作目录 |
| 任务版本 | 计划决定增加新任务版本，原请求、原知识包、原计划和决定均可回查 |
| 幂等与冲突 | 同一请求重放返回原回执；第二次计划决定被拒绝；相同业务编号不会产生第二个任务 |

## 3. 权限与隔离

- 教师可以建立本人任务查询，不能建立群级指标进度或差距办理任务；
- 教务审核人员可以建立自己的只读指标核对任务，不能批准草稿写入计划；
- 不同人员只能查看自己发起的智能体任务，不能通过任务编号读取他人的原话、知识包或计划；
- 信息支持人员读取智能体任务列表得到空结果，不接触业务正文；
- 跨专业群、跨周期或无权对象按不存在处理，不泄露对象标题、数量或状态。

## 4. 知识任务包

每个知识任务包已经固定：

- 学校、专业群、专业和周期范围；
- 本次对象和版本；
- 指标计算截止点、输入摘要和结果摘要；
- 正式进度确认及差距；
- 允许动作与必须人工确认的停止点；
- 任务包摘要和失效时间。

任务包保存在学校侧。旧包不可改写；上下文版本变化后的重新检查和新包建立留到 W9-5C。
