## 1. 使用前提

只有满足以下条件才填写本表：

- 122—132 已按内部评审结论修改；
- 127 已记录评审人、日期和逐项结论；
- 方案已形成明确的冻结候选版本；
- 用户同意开始核对现有实现差异。

本表的目的不是证明已有代码正确，而是判断已有实现是否符合评审后的方案。

## 2. 差异分类

| 分类 | 含义 |
| --- | --- |
| 保留 | 实现与冻结方案一致，可以继续使用 |
| 调整 | 基本方向一致，但对象、流程、权限、文案或交互需要修改 |
| 补建 | 方案要求存在，当前实现缺失 |
| 废弃 | 当前实现与方案冲突或超出范围，应在影响评估后移除 |
| 待验证 | 看似存在，但缺少足够证据判断是否符合 |
| 暂不处理 | 不属于本期冻结范围，保持关闭或隔离 |
