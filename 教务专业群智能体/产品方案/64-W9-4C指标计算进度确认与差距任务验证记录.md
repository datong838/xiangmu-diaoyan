# W9-4C 指标计算、进度确认与差距任务验证记录

> 日期：2026-10-18　状态：合成环境验证通过；下一步 W9-5。

## 1. 验证结论

W9-4C 已把 T10、T11 落实为可运行的确定性链路：指标规则形成版本；每次计算固定规则版本、截止点、成果决定和任务版本；系统产生候选结果；负责人确认后才形成正式进度；差距逐项分类并经负责人决定后建立 W9-4A 任务草稿。

本轮实际得到“目标 3 家、候选实际 1 家、尚差 2 家”。该数字来自 A 企业一条经过确认的成果，而不是两份协议文件。计算完成不会自动成为正式进度，也不会自动派发补充任务。

## 2. 已验证对象和行为

| 对象 | 验证结果 |
|---|---|
| 指标规则与版本 | 目标值、期间、去重键、计入分类、支撑状态和证据角色均被版本化；v1 目标 3、v2 目标 4 同时保留 |
| 计算运行 | 固定规则 v1、2026-06-30 截止点、A/B/C 成果和 D 任务版本 |
| 输入快照 | 每项记录对象版本、人工决定、材料门槛、计入或排除结果及原因 |
| 候选结果 | 两次相同输入均得到 3、1、2，并具有相同输入摘要和结果摘要 |
| 正式进度 | 低于目标时错误确认“已达成”被拒绝；负责人确认“未达成、正式实际 1”成功 |
| 差距 | 形成数量不足、B 工作未完成、C 年度不符、D 工作未开始四类记录 |
| 差距转任务 | B、D 分别建立不同任务草稿；C 关闭为年度不符，不被改造成补材料任务 |

## 3. A、B、C、D 的处理结果

- **A 企业**：分类决定为本年度已完成，指标支撑已确认，具有主证据；扫描件和电子版属于同一成果，只计 1 家。
- **B 企业**：最终分类为本年度推进中，指标支撑待核实；不计入，形成 `work_incomplete`，负责人建立“完成正式签约”任务草稿。
- **C 企业**：业务日期为 2025 年；不计入，形成 `year_mismatch`，负责人关闭差距，不能靠补附件改成本年度新增。
- **D 企业**：无成果候选，固定读取待开展任务版本；不计入，形成 `work_not_started`，负责人建立“完成首次正式洽谈”任务草稿。

## 4. 权限、版本和失败控制

- 专业群负责人可管理规则、发起计算、确认进度和处理差距；
- 教务审核人员只读；教师和信息支持人员不能读取群级指标数字、计算明细或差距；
- 同一幂等键重放返回原回执；第二次进度确认和第二次差距决定返回冲突；
- 规则修改产生新版本，不改写旧计算；
- 计算输入不属于同一范围或指标来源时拒绝；
- 差距建立的任务保持草稿状态，必须回到 W9-4A 另行派发。

## 6. 仍然存在的边界

当前规则只验证“按成果候选计数”的合成数量指标，不能证明学校所有数量、比例、定性或复合指标均已配置。真实规则仍需学校提供口径和样例后逐项验收。真实文件解析、向量检索、智能体自然语言执行、成果编制和学校试点均未在本波完成。

下一步进入 W9-5，先让专业群智能体以受控任务协议调用已经验证的知识检索、任务、成果分类、指标计算和差距办理能力，并保证云动作服务不保存学校资料正文。
