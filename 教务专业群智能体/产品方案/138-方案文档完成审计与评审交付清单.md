## 9. 核心设计口径一致性

| 口径 | 一致结论 |
| --- | --- |
| 平台性质 | 围绕建设对象持续写入和办理，不是静态材料展示站 |
| 智能体 | 贯穿查询、整理、规划、生成、修改和受控执行，不替代人工决定 |
| 知识库 | 面向专业群建设的事实、关系、证据、规则、版本和决定体系，不是通用文件问答库 |
| 事实可信 | 来源、对象、版本、关系、人工决定和建设账本共同保存 |
| 多专业群 | 结构和方法可复用，事实、资料、人员、任务和成果独立 |
| 数据主权 | 学校拥有数据资产完整权利，可部署在校内或学校控制的私域云 |
| 云服务 | 我方只提供动作能力，使用最小任务上下文，不持有学校数据资源 |
| 正式结果 | 由学校人员确认、审核和导出，智能体结果默认为建议或草稿 |
| 文档与代码 | 当前方案决定后续实现，历史代码不能反向决定方案 |
