# W9-2 材料版本与受控文件运行链验证记录

> 版本：v1.1　日期：2026-10-18　状态：核心文件运行链已验证；后续收口已由第 53 份记录验证通过。  
> 方案依据：第 40、43、44、48—50 份方案与记录。  
> 验证边界：只使用合成文字文件，单文件不超过 1 MiB；不代表正式大文件协议、学校真实资料或备份恢复已完成。

## 1. 已实现的运行链

```text
教师登记本人 L1 材料并提交合成原件
  → 服务端计算字节数和 SHA-256
  → 原件写入显式配置的学校侧目录
  → 数据库建立材料、v1、原件元数据、回执和建设账本
  → 教师按退回意见建立 v2，v1 原件继续保留
  → 获授权人员申请五分钟单次凭证
  → 使用时重新检查会话、角色、范围、版本与原件完整性
  → 返回合成文件并立即消耗凭证
```

没有配置 `SCHOOL_FILE_ROOT` 时，写入接口返回依赖不可用，不会把文件写入工程目录、系统临时目录或云端。

## 2. 角色与敏感级别

| 身份 | 当前行为 |
| --- | --- |
| 教师 | 建立和追加本人 L1 材料；只能列出、查看和下载本人材料 |
| 专业群负责人 | 查看本群 L1/L2；可登记 L3 元数据；原件仍只能通过新版本追加 |
| 教务审核人员 | 查看本群 L1/L2并申请受控凭证；不能建立材料 |
| 信息支持人员 | 材料列表为空，已知编号返回不存在式结果，不能获得文件名、数量或正文 |

L3 本波不接收正文，不生成预览或下载凭证。L0 正式公开流程未形成前仍不单独开放。

## 3. 文件与版本约束

- 存储键只含学校、专业群、材料、版本和文件 UUID，不含学校名称、专业名称、人员姓名或原始文件名；
- 文件名、媒体类型、字节数和校验值作为受保护元数据保存；
- `material_blob` 更新和删除由数据库触发器拒绝；
- 建立 v2 时保留 v1 原件和校验值，不覆盖物理文件；
- 同校发现相同 SHA-256 时仅返回 `possibleDuplicate: true`，不自动合并材料；
- 文件服务关闭时，数据库中的材料、版本和建设账本仍保持完整，新增文件写入失败关闭。

## 4. 访问凭证

访问凭证：

- 明文只返回一次，数据库保存摘要；
- 绑定人员、会话、角色分配、材料、材料版本、文件和用途；
- 默认五分钟有效且只能使用一次；
- 使用时重新检查角色仍有效，并验证物理文件字节数和 SHA-256；
- 过期、重放、人员不一致、会话不一致、角色撤销和 L3 正文访问均返回不存在式结果；
- 角色撤销事务会主动撤销该角色尚未使用的凭证。
