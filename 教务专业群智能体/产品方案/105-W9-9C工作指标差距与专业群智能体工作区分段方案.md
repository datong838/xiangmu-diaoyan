# W9-9C 工作、指标、差距与专业群智能体工作区分段方案

> 版本：v1.0　日期：2026-10-19　状态：分段方案已冻结。  
> 前置：W9-9A、W9-9B 已通过；W9-4A—C、W9-5A—C 后端状态机已在合成环境验证。  
> 对应任务：T04、T06—T12，并承接 T05 正式建设要求。

## 1. 本段目标

把已经发布的建设要求继续办理为日常工作、材料提交、负责人审核、成果分类、指标计算、正式进度、差距任务和专业群智能体协助。页面使用同一批任务、工作、材料、指标和决定对象，不建立另一套只供助手演示的数据。

完整主线：

```text
正式建设要求
  → 建立并派发任务
  → 教师持续填写或补充工作记录
  → 固定工作记录版本和材料版本提交
  → 负责人确认、退回或认定证据不足
  → 已确认工作和材料形成成果分类候选
  → 负责人确认分类及指标支撑关系
  → 固定规则、输入版本和截止点计算指标候选
  → 负责人确认正式进度
  → 差距形成补充任务并回到办理链
  → 专业群智能体查询同一事实、准备计划、调用受控动作并在人工控制点停下
```

任务完成、事实确认、材料充足、成果分类、指标支撑和指标达成保持为六种不同结果。

## 2. 三段实现

### W9-9C1：工作记录、提交、退回和确认

- 激活“工作记录”入口，但工作记录仍归属于具体建设任务；
- 负责人可派发草稿任务；责任人可新增或补充工作记录；
- 提交时固定工作记录版本和材料版本；
- 负责人可确认完成、退回补充或确认事实但标记证据不足；
- 任务页连续显示各次任务版本、工作记录版本、提交版本、材料和审核意见；
- 明确显示“任务完成不等于指标达成”。

### W9-9C2：成果分类、指标进度和差距

- 激活“目标与进度”；
- 从确切材料版本形成成果候选，保留建议分类、指标支撑建议和重复材料关系；
- 负责人确认、修改、拒绝或待核实，不改写材料原件；
- 指标规则固定统计期间、目标值、去重和证据要求；
- 计算固定截止点和输入版本，先形成候选值；
- 负责人确认后形成正式进度，差距按原因逐项显示；
- 差距转任务仍由负责人确认并回到任务链。

### W9-9C3：专业群智能体协助办理

- 激活专业群助手和智能体任务列表；
- 用户请求形成稳定智能体任务、版本和固定知识任务包；
- 首批只开放已验证的指标查询、差距跟进、任务状态查询和正式知识查询；
- 页面展示任务理解、已找到内容、缺少条件、办理计划、允许动作和人工停止点；
- 写计划先确认，具体写入结果再确认；
- 支持后续要求、上下文刷新、暂停和恢复；
- 外部模型和开放式语言理解继续关闭，使用确定性意图目录验证产品协议。

## 3. 公共页面原则

1. 工作、指标和智能体都显示当前学校、专业群、周期和角色；
2. 每个写操作展示对象、版本、操作编号和下一步；
3. 页面刷新后从数据库重读，不以浏览器状态作为业务事实；
4. 旧版本和退回意见继续可见，不能用当前状态覆盖历史；
5. 信息支持不看到标题、数量、人员、材料或正文；
6. 教师只办理本人负责且专业范围匹配的任务；
7. 审核人员只读，不能代负责人派发、决定或确认进度；
8. 结果未知时停止自动重发并保留操作编号；
9. 专业群智能体只调用同一正式产品能力，不能绕过权限或人工决定；
10. 页面使用“工作记录、提交材料、审核意见、指标进度、差距事项、办理计划”等学校人员可理解的名称。

## 4. 完成门槛
