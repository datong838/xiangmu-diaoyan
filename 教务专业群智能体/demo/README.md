# 专业群建设工作驾驶舱内部视觉稿

本目录是一张独立的内部视觉探索页面，用于推演专业群 AI 工作站未来首页如何同时呈现建设依据、任务、人员、材料、指标、成果和专业群助手入口。

页面内容依据同级目录中的需求确认单、功能与字段设计、校方沟通展示稿和会议材料。页面中的企业、年度、数量、状态和日期均为演示样例，不代表学校真实数据，也不自动成为正式产品范围。

主要文件：

- `IMPLEMENTATION_PLAN.md`：页面目标、内容结构和验证标准。
- `src/App.jsx`：页面结构、演示数据和交互。
- `src/styles.css`：驾驶舱视觉与响应式规则。
- `design-qa.md`：参考页面与实现页面的视觉检查记录。
- `qa-assets/`：参考截图、实现截图和对比图。

本地预览默认使用：`http://127.0.0.1:4181/`

页面入口：

- `#overview`：建设总览
- `#basis`：建设依据
- `#tasks`：任务与指标
- `#daily`：日常工作
- `#materials`：材料中心
- `#reports`：总结与报告
- `#organization`：组织与权限
- `#pilot`：试点与验收

菜单会更新浏览器地址，刷新、前进和后退后仍能保持当前栏目。
