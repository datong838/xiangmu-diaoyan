## 更新

在三维机械建模目录执行：

```sh
python3 方案导航资料/生成导航.py
python3 方案导航资料/生成导航.py --check
python3 方案导航资料/预览服务.py --port 8843
```

生成器不会修改来源；--check只读检查增删改和二维链接映射。保留稳定节点ID，改标题不改ID，移动来源应显式迁移登记。页面不是实时同步；来源变更后重新生成，旧hash读取返回409。

本机“打开完整阅读页”支持宽屏排版，/raw/ID保留原字节；未登记ID/任意路径404。原HTML与脚本只显示不执行，引用命令不会执行。JSON/契约/回执只作为工件入口，不假称工程正确性已核准。成本快照不逐份展开，避免淹没方案。
